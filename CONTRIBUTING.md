# Contributing

Thanks for your interest! The project is early, so issues and discussion are as
valuable as code.

1. Open an issue before large changes, so we can agree on the approach.
2. Fork, branch, and follow [docs/development.md](docs/development.md) to set up.
3. Make sure `ruff check`, `ruff format --check`, `pytest`, and `npm run build` pass.
4. Open a PR describing *what* changed and *why*.

By contributing, you agree that your contributions are licensed under
AGPL-3.0-or-later.

## Security

Please report vulnerabilities privately through GitHub Security Advisories
(Security tab → "Report a vulnerability"), not through public issues.
